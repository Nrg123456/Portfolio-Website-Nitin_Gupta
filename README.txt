NITIN GUPTA PORTFOLIO WEBSITE (flat version, no folders)
Every file sits in one place, so you can select ALL files and upload them together.

UPLOAD TO GITHUB: open your repository > Add file > Upload files > select ALL files > Commit changes.
Then Settings > Pages > Deploy from branch > main > / (root) > Save.
Make sure index.html is in the main level of the repository.

UPDATE LATER: open admin.html from this folder, edit, press Save changes, press Download updated files.
Unzip website-update.zip and upload every file in it to the repository (replace content.js).
